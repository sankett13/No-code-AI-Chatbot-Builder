Test Page Content - Widget Implementation

This page now uses the JavaScript Widget approach instead of iframe. The benefits include:

  • ✅ No iframe rendering issues
  • ✅ Better mobile responsiveness
  • ✅ Smoother animations and interactions
  • ✅ Direct DOM injection for better performance
  • ✅ More reliable cross-browser compatibility
  • ✅ Easier styling and customization

The widget should appear as a floating button in the bottom-right corner. Try clicking it to open the chat!

Technical Details

Widget API: /api/widget/[botId] - Returns a self-contained JavaScript widget

Iframe API: /api/embed/[botId] - Returns iframe-based embed (alternative approach)
